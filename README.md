# SaaS Invoicing Platform — Backend API

Multi-tenant electronic invoicing SaaS designed for scalability and cloud deployment.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security + JWT
- PostgreSQL
- Hibernate / JPA
- Docker
- AWS (EC2, RDS, S3)

## Features

- Multi-tenant architecture
- Role-based authentication
- Invoice generation
- Customer management
- Subscription plans

## Architecture

Hexagonal / Layered architecture:

controller → service → repository → database

## Deployment

Deployed on AWS using:

- EC2
- RDS PostgreSQL
- S3
- CloudWatch
